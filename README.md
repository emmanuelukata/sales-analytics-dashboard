# PulseSales - Sales Analytics Dashboard

A responsive, high-performance sales analytics dashboard built with vanilla HTML5, CSS3, and modern JavaScript.

## Features
- **Executive KPI Cards**: Real-time Gross Revenue, Total Orders, Average Order Value (AOV), Estimated Net Profit, and Fulfillment Rate with period-over-period delta indicators.
- **Interactive Period Filtering**: Toggle between Last 7 Days, Last 30 Days, Last 90 Days, This Year, and All Time.
- **Custom HTML5 Canvas Charts**:
  - Daily Revenue & Volume line/area chart with custom hover tooltips.
  - Category revenue distribution doughnut chart with hover synchronization.
- **Channel & Product Performance**: Progress breakdown by acquisition channel and top-selling products leaderboard.
- **Transactional Ledger**:
  - Real-time search across customers, IDs, and products.
  - Status filtering (*All, Completed, Pending, Refunded*).
  - Multi-column sorting & pagination.
  - In-line transaction creation, editing, and deletion.
- **Persistence & Export**:
  - Zero backend; all changes persist to browser `localStorage`.
  - One-click CSV export and demo dataset reset.
- **Pure CSS**: Zero CSS variables, hardcoded color palette, modern dark theme.

## Getting Started
Open `index.html` in any modern web browser. No installation or build steps required.
